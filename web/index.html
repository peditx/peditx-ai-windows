REMOTE CONNECTIONS

SSH and SMB

For SSH, name a host alias from ~/.ssh/config or a host whose key you have already verified. PeDitX-AI uses the system SSH client and agent; it never reads private keys or asks for SSH passwords. In Ask mode, approve each remote action. For SMB, PeDitX-AI uses Windows network connections (net use) and can set a mapped drive as Workspace. You can also map the drive in File Explorer and choose it here.
